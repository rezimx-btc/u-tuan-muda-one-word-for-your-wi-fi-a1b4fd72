# One Word for Your Wi-Fi

Microwave — the network named after the one appliance that kills it every time it runs.

## Run it

```sh
python3 main.py
```

This writes the single-word entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
